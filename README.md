# Spokeshot sales page

A single-file sales page for Spokeshot, an embeddable wheel visualizer for wheel and tire shops.

- Live demo it links to: https://thezaysha-debug.github.io/wheel-visualizer-demo/ (an unofficial concept demo that uses California Wheels' public catalog as an example; not affiliated with or endorsed by California Wheels)
- The trial form has no backend. It opens the visitor's email app with a message to ari@thezaysha.com.
- Edit pricing in `index.html` (search for `id="pricing"`).
- `logo.svg` is the wordmark.
